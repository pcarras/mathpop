2. Características e classificação

R(A)
R(A | B)
n (incógnitas)
Grau de indeterminação n − R(A)

 

    Teorema de Rouché-Capelli. Um sistema é possível se e só se R(A) = R(A | B). Sendo possível, é determinado quando R(A) = n e indeterminado quando R(A) < n.
