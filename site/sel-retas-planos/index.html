1. Duas retas

Escreve inteiros, decimais (0,5) ou frações (1/3), ou usa os cursores (inteiros de −9 a 9).

Plano cartesiano

As retas têm as cores das equações. O ponto de interseção só existe quando o sistema é possível e determinado.

2. Classificação

1. Três planos

Cada plano é ax + by + cz = d. Os retalhos são recortados ao cubo [−5, 5]³.

Espaço

Arrasta para rodar (ou usa as setas do teclado). Ponto e reta a vermelho: solução do sistema. Linhas tracejadas: interseções dois a dois.
